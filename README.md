# 05-Bot
A bot for automated management of SCP-CN.

Features include:
* translation reservation management
  * integration with [record archive system](https://github.com/SCP-CN-Tech/Translation-Reserve)
* tiny article management
* contest results fetching and image generation
* mass rollback against destruction
* mass deletion against destruction
* mass tag update
* mass component variable update
* uncommon tags lister
* orphaned fragment lister
